RANGE ROVER - MATERIAL FIXED (DQP Studio)

1. Import this unitypackage.
2. Wait until Unity finishes compiling the importer script.
3. Open Assets/DQPStudio/RangeRover/Range_Rover_Material_Fixed.dqpcar.
4. Drag the generated model from the Project window into your scene.

The .dqpcar file contains the model, all six textures, 28 repaired materials,
75 meshes, hierarchy, and the original two-door animation. It uses a custom
extension so it will not conflict with Piglet, glTFast, UniGLTF, or another
.glb importer already installed in the project.

Shader selection:
- Uses Universal Render Pipeline/Lit when URP is installed.
- Falls back to the built-in Standard shader otherwise.

If the model does not appear immediately after package import, right-click
Range_Rover_Material_Fixed.dqpcar and choose Reimport after script compilation.
